# Маяк (Mayak P2P Messenger)

Автономный децентрализованный P2P & Mesh мессенджер для **Android** и **Windows** без центральных серверов, без регистрации по номеру телефона или почте и без VPN-проксирования.

## Возможности
- **Сквозное шифрование по умолчанию:** все сообщения, файлы, звонки и рация шифруются непосредственно на устройствах собеседников.
- **Полная автономность без интернета:**
  - Локальный Wi-Fi (роутер или точка доступа, автоматическое обнаружение узлов).
  - Bluetooth (BLE LowPower + RFCOMM для сопряжённых устройств без включения Wi-Fi и без запроса PIN).
  - Мульти-хоп Mesh (`A ↔ B ↔ C`) с зашифрованным буфером отложенной доставки.
- **Межрегиональная и международная связь (Zero-Server):**
  - Прямой UDP Hole Punching с синхронным UTC-рандеву, автоматический UPnP-IGD / NAT-PMP и глобальный IPv6.
  - Зашифрованные голосовые и видеозвонки, рация (PTT), обмен файлами и медиа, общий канал и офлайн-карта.
- **Удобный обмен контактами:** сохранение PNG QR-визитки и чтение QR из галереи (Android) или файла (Windows).
- **Удобные обновления:** проверка новых версий из [GitHub Releases](https://github.com/lasaniaden/Mayak-messenger/releases/latest) прямо при запуске.

## Установка
1. Откройте раздел **[Releases](https://github.com/lasaniaden/Mayak-messenger/releases/latest)** справа на странице репозитория.
2. Для **Android**: скачайте и установите `mayak-android-vX.Y.Z.apk` (релизы подписаны единым ключом и обновляются поверх старой версии с сохранением чатов).
3. Для **Windows**: скачайте `mayak-windows-vX.Y.Z.zip`, распакуйте в удобную папку и запустите `p2p_mesh.exe`.

## Подключение между городами / странами
1. В *Настройки → Подключения → Межрегиональная связь* включите тумблер **«Межрегиональный режим»** и дождитесь статуса STUN (3–5 сек).
2. Нажмите **«+ Новый узел» → «Сохранить QR»** и отправьте картинку собеседнику (после этого не нажимайте «Обновить адрес»).
3. Оба участника выбирают QR друг друга через **«QR из галереи / файла»** и ждут 20–30 секунд.
