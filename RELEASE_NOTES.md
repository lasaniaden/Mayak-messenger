# Маяк v3.2.4

### Полная переработка голосовых, аудиоплеера и видеозвонков (ноль PowerShell и ноль `qedit.dll`)
- **Нативный автономный аудиоплеер (`flutter_soloud` / C++ SoLoud + miniaudio)**: полностью удалён PowerShell-плеер на Windows. Голосовые сообщения и аудиофайлы читаются прямо в оперативную память (`loadMem`), мгновенно закрывая файл — 100% работают кириллические пути, Windows N/KN, пауза, перемотка и никогда не блокируется папка приложения.
- **Единый формат голосовых (`.wav` 16 кГц моно)**: Android и Windows теперь записывают универсальные голосовые сообщения, которые гарантированно проигрываются на обеих платформах (старые `.m4a` на Android продолжают поддерживаться).
- **Нативные P2P видео- и голосовые звонки (`flutter_webrtc` M144+)**: полностью удалены PowerShell и DirectShow `qedit.dll` (больше никаких `WerFault.exe`, гаснущих камер Razer/UVC и срабатываний Dr.Web).
  - Нативный C++ захват камер Windows (`CaptureSinkFilter`), Camera2 на Android и показ экрана WGC на Windows.
  - Промышленное эхоподавление и шумодав **WebRTC AEC3 + NS + AGC2 + NetEQ** без эха и с нормальной громкостью речи.
  - Весь сигналинг (Offer/Answer/ICE) идёт через наш зашифрованный бессерверный P2P-канал с автоматической фрагментацией SDP поверх UDP.
- **Исправлен баг «призрачного файла с абракадаброй» и снижены лаги Android**: при удалении файла отправителем во время загрузки уходит явный кадр `FILE_REVOKED`, поток немедленно останавливается, `.part` удаляется, а опоздавшие чанки больше не создают битых записей; перерисовка UI при скачивании снижена до 2.5 Гц.
- **Чистота от Play Protect**: в `AndroidManifest.xml` добавлена жёсткая зачистка `tools:node="remove"` для всех запрещённых транзитивных разрешений, а публикация GitHub Release разделена на `create` + `upload --clobber`.
