## Что нового в Маяк v3.1.0

- **Постоянный межрегион без привязки к IP (Mainline DHT BEP-44):**
  - Межрегиональный режим теперь запоминается и работает автоматически в фоне при каждом запуске.
  - Реализован собственный компактный клиент Mainline DHT (`lib/mayak_dht.dart`: BEP-44 + BEP-42 + BEP-43 read-only) со встроенным CIDR-фильтром проблемных подсетей (Scaleway/GlobalTeleHost).
  - При смене сети (`Wi-Fi ↔ 4G`) Маяк сам публикует зашифрованный `IP:порт` в приватном суточном слоте для каждого контакта, а при открытии чата с оффлайн-другом — сам находит его новый адрес и пробивает туннель.
  - В *Настройки → Подключения* добавлен тумблер включения/отключения внешнего DHT.
- **Постоянный Маяк-ID (Crockford Base32):** 61 символ без путаных букв `I/L/O/0` с контрольной суммой и кнопкой смены `nospam` (в *Настройки → Подключения*).
- **Детектор выхода из сна (Windows Modern Standby):** автоматическое восстановление сокетов и обновление координат после пробуждения ноутбука.
- **Починено скачивание старых файлов по кнопке над блюром:** исправлен поиск файла в истории чата и кэше, сброс зависших попыток передачи и понятное уведомление, если файл удалён отправителем.
