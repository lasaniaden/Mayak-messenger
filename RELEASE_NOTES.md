# Маяк v3.1.6

### Автообновление на Windows без PowerShell (схема TGWSProxy / Telegram Desktop)
- **Полностью убран PowerShell из автообновления ПК** (раньше поведенческий анализ Dr.Web молча блокировал запуск `.ps1` из `%TEMP%`, поэтому после загрузки ползунка ничего не обновлялось).
- **Новый нативный механизм прямо внутри Маяка**:
  1. Встроенный чистый Dart-распаковщик ZIP (без единого внешнего процесса) распаковывает архив во временную подпапку и проверяет `p2p_mesh.exe`.
  2. Старые `.exe` и `.dll` переименовываются на лету в `*.old` (Windows NTFS разрешает это даже для запущенного приложения и при открытом Проводнике!), а на их место мгновенно переносятся новые файлы.
  3. Запускается обновлённый `p2p_mesh.exe --updated` (добавлено ожидание освобождения Single-Instance Mutex до 6 секунд), а при старте новая версия сама удаляет остатки `*.old`.
- Включает все исправления `v3.1.4`–`v3.1.5` (голосовые на ПК с русскими именами, стабильный статус «В сети» по UDP, видео в межрегионе, WinRT-камера без `qedit.dll` и кнопка выгрузки журнала диагностики).
