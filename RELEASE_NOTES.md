# Маяк v3.2.5 — Крупный стабилизационный патч (по итогам полевых тестов)

### Исправления критических багов
- **Исправлен краш Android при завершении звонка:** перед уничтожением `MediaStream` и `RTCPeerConnection` рендереры `RTCVideoView` теперь отвязываются заранее с паузой на кадр Flutter — убран нативный EGL-краш.
- **Исправлен зависающий экран звонка у собеседника:** сигнал `CALL_END` отправляется серией из 3 пакетов (0 / 250 / 600 мс), чтобы обрыв связи гарантированно доходил даже при потере UDP-пакета.
- **Поддержка второго одновременного звонка (`CALL_BUSY`):** если вы уже в разговоре, второй звонящий получает статус *«Абонент занят в другом звонке»*, а вам приходит уведомление о пропущенном вызове.
- **Исправлено скачивание видео и зависания файлов на 56% / 68%:**
  - Лимит UDP-чанков в приёмнике поднят с `40 000` до `500 000` (видео больше 8.8 МБ больше не отбрасываются и не сбрасываются с 2% в 0%).
  - Таймаут TCP-watchdog увеличен с 16с до 35с (и 60с во время активной передачи файлов), чтобы скачивание тяжёлых файлов не рвалось на полпути.
- **Исправлена ошибка парсинга `udp:` и IPv6 (`parseEndpoint`):**
  - Убран баг, из-за которого при подключении втроём два контакта с адресами `udp:...` считались «одинаковым IP» и затирали друг друга.
  - Убран спам `Invalid internet address 2a03` и `Failed host lookup: 'udp'`.
- **Приватность адресной книги:** отключено автоматическое копирование чужих контактов в `peer_sync`.
- **Убраны дубли сообщений и улучшена локальная связь:** добавлена строгая дедупликация входящих текстовых сообщений по `msgId` и запрещена повторная отправка по UDP/BLE, если пакет уже ушёл по TCP.
- **Починена рация (PTT):** убрана блокировка передачи при выключенном автоприёме, убрана задержка перед стартом микрофона, увеличен таймаут тишины (1.4с) чтобы окошко приёма не пропадало.
- **DHT PEX (обмен узлами между собеседниками):** при подключении устройства делятся до 20 живыми DHT-узлами — помогает телефонам, у которых оператор режет стандартный порт 6881.
- **CI-контроль качества:** в GitHub Actions добавлены автоматические `flutter analyze` и `flutter test` перед сборкой релизов.
