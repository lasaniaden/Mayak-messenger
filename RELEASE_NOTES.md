# Маяк v3.2.7 — Фикс 2-секундных разрывов TCP, умная докачка файлов (99% → 100%) и ползунок отправки

### Что исправлено и добавлено
- **Убран бесконечный 2-секундный разрыв TCP в локальной сети:** `connectToHost` больше не открывает повторный сокет к уже подключённому пиру, а `onHello` сохраняет живой сокет и закрывает лишний дубль, не обрывая передачу тяжёлых видео.
- **Умная докачка файлов вместо сброса в 0%:** если загрузка остановилась на 99% (или любом проценте) и вы нажали кнопку прогресса, клиент отправляет список недостающих чанков (`missing` / `fromIdx`) — отправитель досылает только потерянные фрагменты, а не перекачивает весь файл с нуля.
- **Ползунок отправки файла у отправителя:** на карточках отправляемых видео, фото и файлов теперь отображается живой прогресс-бар (`Отправка XX%`), чтобы было видно, на сколько файл уже передан собеседнику.
